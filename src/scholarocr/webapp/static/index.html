    ScholarOCR needs a model to read scanned pages. Use your Google account through Antigravity CLI, or add an API key.

    1. Install Antigravity CLI so that agy is on your PATH.
    2. Run agy once in a terminal and sign in with your Google account.
    3. Check again.
